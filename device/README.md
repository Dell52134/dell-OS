# Device tree

Target: Samsung Galaxy Mini 2 GT-S6500D, codename `jena`.

Candidate upstream device tree:
- Repository: https://github.com/TheWhisp/android_device_samsung_jena
- Branch used during initial inspection: `jellybean`

This is a source reference, not a verified working device configuration.
Before building, inspect its BoardConfig, product makefiles, init files, fstab,
proprietary-file list, and kernel expectations. Confirm that the configuration
matches the GT-S6500D variant and its partition layout.
