# DELL OS packages

Planned first-party Android applications and resources:

- DELL Shell — home screen and launcher experience.
- DELL Settings — project-specific settings interface.
- DELL Files — file browser.
- DELL Music — local audio library interface.
- DELL System Info — device and build information.
- DELL Terminal — terminal shortcut/interface, subject to Android 4.1 compatibility.
- Boot animation — DELL OS startup branding.

These are planned components, not completed or installable applications yet.
Keep Android 4.1.2 API compatibility in mind and avoid relying on modern Android APIs.
